# Geographic Data Attribution

`iran_city_coordinates.csv` contains coordinates matched to the canonical Iran
city list from the GeoNames Iran export.

- Source: https://download.geonames.org/export/dump/IR.zip
- License: Creative Commons Attribution 4.0
- Attribution: GeoNames (https://www.geonames.org/)

Only unambiguous normalized Persian-name matches are included. Cities without a
reliable match intentionally keep null coordinates and remain visible in order
counts without an inaccurate map marker.
